# Generated LuaLS Stubs

Files in this directory are generated from C++ metadata.

Do not edit them by hand.

Update generated stubs:

```sh
make luals-stubs
```

Check generated stubs:

```sh
make check-luals-stubs
```

Run the full project gate:

```sh
scripts/run_tests.sh
```

The authored-document and runtime Lua stubs are separate LuaLS library roots.
